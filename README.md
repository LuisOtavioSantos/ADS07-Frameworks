# ADS07 - Frameworks

Exemplos da Aula 3 de Introdução ao Desenvolvimento de Sistemas Web.

Antes de tudo, instale o [Node.js](https://nodejs.org) (versão LTS).

## 01-bootstrap

Não precisa instalar nada. Abra o `index.html` no navegador ou use o Live Preview do VS Code.

## 02-react

```bash
cd 02-react
npm install
npm run dev
```

Abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

## 03-react

```bash
cd 03-vue
npm install
npm run dev
```

Abra o endereço que aparecer no terminal (normalmente http://localhost:5174).

## 04-angular

```bash
cd 04-angular
npm install
npm start
```

Abra http://localhost:4200.

## Para parar

No terminal, `Ctrl + C`.
